## 一、界面总览

**顶部固定**（不随内容滚动）：

```
◈ Kontakt 音色库管理器   [概览|音色库列表|乐器中心|问问AI|健康检查|维护|音色地图]   ⚙ 设置
 音色库路径: D:\Kontakt Libraries | D:\Kontakt Libraries\Abbey Road | …
```

| 标签页 | 干什么 |
|---|---|
| **概览** | 总览统计 + 「建议做这些」引导 + 扫描入口 |
| **音色库列表** | 所有音色库（入库状态 / 存放位置 / 封面） |
| **乐器中心** | 按类别浏览 NKI 乐器、搜索、收藏、试听 |
| **问问 AI** | **内置 Agent**：查手册、找音色、**直接试听** |
| **健康检查** | 找缺失文件 / 杂质 / 缺封面，一键修 |
| **维护** | 孤儿文件 / 重复文件 / 快照 / 库关系 |
| **音色地图** | **音色相似度可视化**（聚类 + 框选 + 批量操作） |

**⚠️ 设计上整个框架固定、只有内容区滚动** —— 主界面不会出现整页滚动条。

## 二、第一次使用：三步走

```
① 设置          →  添加音色库根目录
② 概览 → 开始扫描  →  建立索引（首次较慢）
③ 开始用        →  乐器中心 / 问问AI / 音色地图
```

**具体操作**：

1. 点右上角 **「⚙ 设置」** → 添加你的音色库根目录
   （例如 `D:\Kontakt Libraries`、`D:\Kontakt Libraries\8dio`、`D:\Kontakt Libraries\Orange Tree`）
2. 回 **「概览」** → 点 **「开始扫描」**
3. 扫描完成后，右侧会显示各库的 **「已建库 / 未建库」** 状态

## 三、概览

**这是首页，三块内容**：

| 区块 | 说明 |
|---|---|
| **统计卡片** | 库数 / 乐器数 / 采样数 / 根路径数 |
| **💡 建议做这些** | **轮换海报**：自动提示「哪些库缺封面」「哪些库没建知识库」等 |
| **扫描区** | 开始扫描 / 增量扫描 |

**💡 建议海报的操作**：

- **`‹` `›`** 手动切换 · **5 秒自动轮换** · **鼠标悬停会暂停**（正在读时不被翻走）
- 点卡片 → **弹窗显示完整内容** → 里面有 **「去处理」** 按钮可直接跳到对应页面
- **「重新体检」** 重新计算建议 · **「含重复扫描」** 会连重复文件一起扫（更慢）

## 四、音色库列表

**看所有音色库**：

| 列 | 含义 |
|---|---|
| **库名** | 产品名 |
| **状态** | **已入库 / 未入库**（未入库的不会被「乐器中心」收录） |
| **路径** | 存放位置 |
| **封面** | 自动从库目录里找图 |

**操作**：

- **点库名** → 进入该库详情（乐器列表 + 可试听采样）
- **试听区** → 点 ▶ 直接播放（**内嵌播放器，不用切软件**）
- **「换一批」** → 随机再抓几个采样试听

## 五、乐器中心

**按类别浏览所有 NKI 乐器**。

| 功能 | 说明 |
|---|---|
| **分类筛选** | 左侧类别树（打击乐 / 弦乐 / 铜管 / 钢琴键盘 / 氛围音效…） |
| **搜索** | 按乐器名 / 库名搜索 |
| **搜索范围切换** | **可切换「全字匹配 / 包含 / 关键词（英文→中文）」** |
| **收藏** | 星标常用乐器 |
| **试听** | 选中乐器 → 试听区可播放它对应的采样 |
| **「🔍 找相似的」** | 用声学特征找音色相近的乐器 |

**💡 小技巧**：搜索框支持 **英文关键词 → 中文语义**（例如输 `snare` 能匹配到相关乐器），因为库里全是英文命名。

## 六、问问 AI

**这是核心功能** —— 一个能读你手册、能翻你音色库、**还能直接放给你听**的 Agent。

### 6.1 三种会话模式

| 模式 | 用途 |
|---|---|
| **单库问答** | 选定一个库，问它的手册内容（**知识库未建时会提示**） |
| **跨库问答** | 问全局问题：「我有哪些弦乐库」「哪些库还没建知识库」 |
| **跨库分支** | 在同一会话下开分支，保留上下文分别追问 |

### 6.2 权限档位（**右上角那个下拉**）

| 档位 | Agent 能做什么 |
|---|---|
| **🔒 只读**（默认） | 只能查索引与知识库 |
| **✏️ 读写** | 可跑**只读命令**（自动放行）；**改文件会逐条问你** |
| **⚡ 完全** | 全部放行、**不再逐条确认**（信任当前任务时才用） |

### 6.3 怎么问才好用

**✅ 好的问法**：

| 你想干什么 | 这样问 |
|---|---|
| **查手册** | 「8Dio Adagietto 怎么切换演奏法？」 |
| **找音色** | 「**找 5 个 Cymbals 音色并提供试听**」 |
| **要更具体的镲片** | 「找 5 个 Crash 镲片试听」 |
| **描述性找音色** | 「找几个**明亮 + 有打击感 + 噪声多**的音色」 |
| **按风格** | 「找 5 个**电子风格**的镲片」 |
| **全局统计** | 「我们总共有哪些说明书、哪些还没建库」 |
| **建知识库** | 「把 Odeholm Drums 的说明书转成知识库」 |
| **写 KSP** | 「帮我写一个 KSP 脚本，让所有键位都发出 C3 音高，然后编译验证」 |

**⚠️ 关于「找音色」**：

- **它会自动挑【名字真含关键词】的**（**不是靠"听起来像"猜的**）
- **每个推荐会给一批同类采样**（不同力度 / 麦位 / 尺寸），**让你有挑选余地**
- **全部保证能点开有声**（**不能试听的它不会算进数量** —— 会如实告诉你凑到几个）
- **风格不限** —— 你说「Cymbals」时，**电子镲片、电影感镲片同样算合格的 Cymbals**

### 6.4 试听播放器

**Agent 找的音色会渲染成【对话内的播放器】** —— 点 ▶ 直接听，支持：

- **多组播放**（每组一个卡片，对应一个库）
- **一行两个**（省地方）
- **同一时刻只播一个**（点新的会自动停掉旧的）
- **答案里的播放器数量 = 屏幕上看到的数量**（它不会多报）

### 6.5 其它

- **插话引导**：生成过程中在输入框打字并发送 ⇒ 变**橙色虚线气泡**，**Agent 会采纳**
- **停止**：生成中发送按钮变红 **「停止」**
- **上传图片**：点 🖼️ 上传本地截图（也支持 `Ctrl+V` 粘贴）
- **`@` 引用路径**：输入框打 `@` 弹出库/目录候选，`↑/↓` 选、`Enter`/`Tab` 插入
- **思考强度**：输入行右侧（**Auto / low / high**），Auto = 由模型自控

## 七、健康检查

**找问题 + 一键修**：

| 功能 | 说明 |
|---|---|
| **重新检查** | 重新扫描所有问题 |
| **一键清理杂质** | 清理零字节 / 临时文件等杂质 |
| **补全封面** | 自动从库目录找图补封面 |

## 八、维护

| 功能 | 说明 |
|---|---|
| **扫描孤儿** | 找「索引里记着但实际不存在」的库/文件 |

## 九、音色地图

**把「音色相似度」画成一张图** —— 这是本工具最有特色的功能。

### 9.1 四个步骤（**必须按顺序**）

```
① 声学特征   →  ② 开始分析   →  ③ 重算地图   →  ④ 乐器地图（可选）
   (纯 CPU)      (MERT 嵌入)     (UMAP+HDBSCAN)   (按 NKI 名聚合)
```

| 按钮 | 干什么 | 耗时 |
|---|---|---|
| **① 声学特征** | 提取 32 维可解释特征（**不用模型，很快**） | 快 |
| **② 开始分析** | 跑 MERT 语义嵌入（768 维）→ 生成坐标 | **慢**（可暂停） |
| **③ 重算地图** | **不重提特征**，只重跑降维与聚类（**换参数后用它**） | 中 |
| **④ 乐器地图** | 把采样级特征聚合成乐器级地图 | 中 |
| **暂停** | 随时暂停/继续后台任务 | — |

**⚠️ 先跑 ②，再跑 ③** —— 没有嵌入就没法降维。

### 9.2 怎么看这张图

- **每个点 = 一个采样**，**距离越近声音越像**
- **颜色 = 聚类**（HDBSCAN 自动分的组）
- **图例**：竖排每项一行；**点名字**高亮该簇（其余变暗）；**点 ▶** 播该簇代表样本
- **簇命名**用「占比最高的库名」 —— **若一个簇混了多个库，名字会带 (混合) 提示**
- **灰色点 = 噪声**（不属于任何稠密簇的孤立采样，**这是正常的**）

### 9.3 交互

| 操作 | 效果 |
|---|---|
| **滚轮** | 缩放 |
| **拖拽** | 平移 |
| **重置视图** | 回到初始缩放/位置 |
| **点一个点** | 右侧详情面板：**播放器 + 「最相似的 12 个」** |
| **拖拽框选** | **选区条出现**，显示「已选 N 个（跨 M 个库）」；**被选中的点有绿色描边** |

### 9.4 框选后的批量操作

| 按钮 | 干什么 |
|---|---|
| **▶ 批量试听** | 依次播放选中项（**日志会报「播放 N 段，跳过 M 段」**） |
| **打标签** | 给选中项批量打标签（**居中弹窗**） |
| **导出 CSV** | 导出库名/文件名/聚类/坐标 |
| **取消选择** | 清空选区 |

### 9.5 导出

点 **「导出」** → 询问格式：

- **PNG** —— 深色底图片（不是黑底透明）
- **CSV** —— 含库名 / 文件名 / 聚类 / 坐标

### 9.6 调参（可选）

改参数后点 **③ 重算地图** 看效果：

| 参数 | 影响 |
|---|---|
| **近邻**（大 → 看全局结构；小 → 看局部簇） | 地图形态明显不同 |
| **度量**（余弦 / 欧氏） | 产出布局不同 |

**⚠️ 调参会改变聚类结果** ⇒ **之前的框选/标签可能对不上**，重算后建议重新看。

## 十、常用技巧

**🔍 搜索**

- **乐器中心**支持「英文关键词 → 中文语义」（库里全是英文名，很好用）
- **问问 AI** 里可以直接说中文需求，不用翻译成英文

**🎧 试听**

- **试听缓存会自动清理**（超 3 天或超 300 MB）
- **首次播某个采样会慢 10~40 ms**（要解码 + 响度归一化），之后就快了
- **`.nkx` 加密容器**在拿不到 NI 产品密钥时无法试听 —— **会如实提示，不会假装成功**

**🤖 问 AI**

- **问得越具体越好**：「找 5 个 Crash 镲片试听」优于「给我点镲片」
- **想换方向就直接说**：「换成更亮的」「只要交响的」
- **它会承认自己做不到** —— 例如「该库只有预览、没有可试听的采样」

**📦 数据安全**

- **数据全在 `data\` 里**，**迁移时整个文件夹一起搬**
- **音色库文件永远不会被改动**（本工具只读）

### Kontakt Library Manager — User Guide

**Tabs**: Overview · Libraries · Instruments · Ask AI · Health · Maintain · Sound Map

**First run**
1. ⚙ Settings → add your library root folders
2. Overview → **Start Scan**
3. Use Instruments / Ask AI / Sound Map

**Ask AI** — a built-in agent that reads your manuals, searches your library, and **plays audio inline**.
- **Permission tiers** (top-right of the chat panel): Read-only / Read-Write / Full
- **Good prompts**: "Find 5 Cymbals and let me audition them" · "How do I switch articulations in 8Dio Adagietto?"
- **When finding sounds**: it prefers items whose **filename really contains the keyword**, gives a
  **batch of similar samples per pick**, and **only counts items it can actually play**.
  Electronic/processed cymbals count as cymbals — style is not restricted.
- **Inline players**: click ▶ to audition. The number of player groups always matches the answer.

**Sound Map** — visualises timbre similarity (MERT embeddings → UMAP → HDBSCAN).
- Run in order: **① Features → ② Analyze → ③ Rebuild Map → ④ Instrument Map (optional)**
- Dot = one sample; closer = more similar. Colour = cluster. Grey = noise (normal).
- **Drag to box-select** → batch audition / tag / export CSV.

**Data** lives in `data\`. Move the whole folder to migrate. Your library files are never modified.
